一、避障与雷达

1.1 避障通道说明

AGV界面避障通道与兴颂避障雷达通道的对应关系如下表所示：

AGV界面显示避障通道 功能 兴颂避障通道 对应关系(从1开始) 对应关系(从0开始)
0低速前进6310
1高速前进6221
2低速后退6132
3高速后退6043
4手动区域/原地旋转5954
5自定义区域5865
6自定义区域5776
7取/放货5687
8自定义区域5598
9自定义区域54109
10自定义区域531110
11自定义区域521211
12自定义区域511312
13自定义区域501413
14自定义区域491514
注意事项：
  • 取/放货通道（通道7）条件：① 取放货任务带bit13/14/15标记位；② 低于运行高度"Lifter load run height"；③ 如果取放货路径勾了bit10，且配置了避障通道，优先bit10功能。
  • 目前使用的雷达中只有兴颂避障是从大往小的通道设定，其他无特别说明的避障雷达按照正常的小往大通道进行配置。
  • 车身所有避障雷达均共用同一个避障通道，无单独给某个雷达设定特殊通道的功能。
  • 带安全型避障雷达的通道不一致（S300：8个；基恩士：16个）。
  • 雷达ID定义：ID0-顶部导航雷达；ID1-预留；ID2-左侧；ID3-前侧；ID4-右侧；ID5-斜照。

1.2 雷达标定

标定条件：重新安装雷达 / 调节过雷达安装位置 / 角度都需要重新去标定雷达。
要求：通过远程客户端的键盘去控制叉车标定。

二、相机与路径

2.1 相机识别参数

相机识别参数说明如下：

参数编号 参数说明
1相机安装角度（弧度）：如果识别取货时栈板有角度偏差，可通过调整此参数
3相机安装位置Y轴：如果识别取货左右有偏差，可通过调整此参数
4栈板插孔高度
5栈板插孔宽度
6栈板内宽
7开启相机识别功能
8填cam_pose_fix_x（当取货时，栈板端面无法接触到叉尖货物检测开关/撞击栈板时，调整此参数）
重要提示：
  • 栈板插孔的高度和宽度需根据实际现场的栈板尺寸做调整。
  • 调整相机安装位置前先调整角度（V）再调整左右（Y）。
  • 识别距离约束：叉尖到栈板端面最短50-70cm，最远1.8m，栈板偏差角度越大，识别距离越长。
  • 路线要求：禁止原地旋转后直接进入识别路线，原地旋转完后需走一段直线再进入识别路线。
  • 路径文件：top_cam_ground_coeff.ini
  • 相机标定后检查标定数据，如偏差大则重新标定。

2.2 路径标记位配置

标记位 功能说明 应用范围
bit2反光柱定位；使用反光柱定位需扫描到≥3个柱子才有效路径段勾选
bit9屏蔽叉尖检测传感器路径段勾选
bit10选用特定避障——在路径信息"用户储存信息2"中填对应的避障通道路径段/站点选用
bit11盲取功能，只要在路径上触发了货物检测弹片就认为取到货取货路径段和站点勾选
bit12开启相机识别功能，反之禁用相机识别功能取放货路径段和取放货站点勾选
bit13允许叉臂提前升/降到指定高度路径勾选
bit14, bit15取放货路段，叉臂禁止升降动作路径勾选
补充说明：
  • 如果带栈板识别功能，叉尖-栈板端面距离 ≥ 0.5m。
  • 建议末端速度0.3，前一段路径0.4/0.5，或者更慢。

三、运动参数

3.1 举升参数

注意：该序列表不代表最终这个参数的位置，根据实际英文来对应位置！默认厂内已调好该部分参数，无特殊情况下勿动！
参数编号 参数说明
65自动模式叉臂下降最大速度
66自动模式叉臂下降最小速度（距离目标高度100mm启用），同上升
67自动模式叉臂预举升高度；单位：m
68自动模式上升最大速度
69自动模式上升最小速度
70自动模式叉臂默认运行高度；单位：m
71手动模式叉臂设定举升最高高度（仅适用JT手柄）；单位：m
98自动模式叉臂设定举升最高高度，默认情况下需比上限位传感器高度低2cm；单位：m

参数说明

  • 预举升高度：取货/卸货的二次抬升高度。
    • 取货：调度下发500mm的高度进行取货，AGV进入到工位后以500mm+预举升高度把货物取出来。
    • 卸货：调度下发500mm的高度进行卸货，AGV进入工位前会抬升至500+预举升高度进入到工位；进入工位后，减去预举升高度放下托盘。
  • 自动默认运行高度：当AGV完成取卸货后，正常行驶在路径上时叉臂会以设定的运行高度去行驶。

五、自动门配置

5.1 基本配置

参数编号 参数说明
102开启自动门模式（1）
目标路径：/release/config/mfio_control_data.ini

5.2 MFIO 参数说明

参数名 说明
io_inputIO输入位（对应MFIO接的IN位——没接填0）
io_outputIO输出位（对应MFIO接的OUT位）
mfio_group_id电梯ID（默认0）
mfio_idMFIO_ID（MFIO从机ID）
route_id自动门路径ID（需要交互的路径ID），0/-1无效
node_id节点ID，0/-1无效

5.3 IO 对应关系

IO out1 out2 out3 out4
io_output1248
配置举例：
  • 电梯开门到位信号接MFIO的IN1，电梯开门信号接OUT1。
  • 路径ID：56——这段路径需要请求电梯开门到位信号和收到开门到位信号之后才会释放AGV继续行走，所以 io_input = in1, io_output = out1。
  • 如果控制out4，io_output就填8；如果需要同时控制out1和out4，io_output就填9（相加）。以此类推，io_input同理。

5.4 路线配置

需在路径配置中设置自动门相关的路由和节点信息，确保AGV经过指定路径时能正确请求电梯开门。
